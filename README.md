# 🧮 Python Calculator

Консольный калькулятор на Python: без внешних зависимостей, с интерактивным режимом, функциями и защитой от «опасного» ввода.

```text
> 2 + 2 * 2
6
> sqrt(16) + 2^3
12
> sin(radians(30))
0.5
> ans * 10
5
```

## Возможности

- Операции `+` `-` `*` `/` `//` `%` `**` (или `^`) и скобки
- Функции: `sqrt`, `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `radians`, `degrees`, `ln`, `log`, `log2`, `log10`, `exp`, `abs`, `round`, `floor`, `ceil`, `factorial`, `min`, `max`
- Константы `pi`, `e`, `tau`; переменная `ans` хранит последний результат
- Безопасность: вместо `eval()` используется разбор через `ast`, поэтому выполнить чужой код через ввод нельзя
- Защита от «зависания» на гигантских числах (например, `9 ** 9 ** 9`)
- Понятные сообщения об ошибках (деление на ноль, неверный синтаксис и т. д.)
- Только стандартная библиотека, Python 3.10+

## Запуск

```bash
git clone https://github.com/<ваш-логин>/python-calculator.git
cd python-calculator

python calculator.py                 # интерактивный режим
python calculator.py "2 + 2 * 2"     # одно выражение
```

> На macOS и Linux используйте `python3`. Выражения со `*`, `(` и `^` берите в кавычки — иначе их обработает командная оболочка.

В интерактивном режиме: `help` — справка, `exit` (или `q`, `Ctrl+C`) — выход.

## Примечания

- `sin`, `cos`, `tan` работают с радианами; для градусов используйте `radians(30)`.
- `log(x)` — десятичный логарифм, `log(x, основание)` — по произвольному основанию, `ln(x)` — натуральный.
- Десятичный разделитель — точка: `2.5`.
